Above Architects - Design Improvements Roadmap
Date: 2026-04-03
References reviewed:
- https://www.maramani.com/
- https://topnotchplan.com/

==================================================
1) HIGH-IMPACT IMPROVEMENTS TO ADD
==================================================

1. Add a trust strip under the hero section
- Purpose: Build confidence immediately.
- Suggested items:
  - 29+ Projects Delivered
  - Licensed Architectural Team
  - On-Time Delivery Commitment
  - Sustainable Design Approach
- UI notes:
  - Icon + short label format
  - Keep compact and mobile friendly

2. Upgrade project cards with metadata badges
- Purpose: Make portfolio feel premium and informative.
- Add fields on each project card:
  - Project type (Residential, Commercial, etc.)
  - Location
  - Year
  - Built area (sqm)
  - Stage
- Add stage badges:
  - Concept
  - Design Stage
  - Under Construction
  - Completed

3. Add category filter chips on Projects page
- Purpose: Help users discover work faster.
- Suggested categories:
  - Residential
  - Commercial
  - Institutional
  - Hospitality
  - Mixed Use
- Optional second-level filters:
  - Budget range
  - Plot size
  - Floors
  - Bedrooms

4. Add one featured case-study section on homepage
- Purpose: Tell one high-value story with outcomes.
- Block content format:
  - Challenge
  - Approach
  - Result
- Include 3 measurable outcomes where possible:
  - Area delivered
  - Timeline
  - Cost efficiency or value outcome

5. Add social proof section before final CTA
- Purpose: Increase conversion with trust evidence.
- Include:
  - 3 client testimonials
  - Project type + location per testimonial
  - Optional client/partner logo row

6. Add a secondary CTA in the middle of homepage
- Purpose: Capture user intent earlier.
- Two action paths:
  - Browse Projects
  - Request Consultation

7. Improve section rhythm and depth
- Purpose: Increase premium visual feel.
- Add:
  - Alternating section backgrounds
  - Subtle gradient overlays
  - Better spacing contrast between sections
  - Editorial image/text alternation

8. Add "Design by Need" quick-entry blocks
- Purpose: Help undecided users enter portfolio quickly.
- Suggested blocks:
  - By Budget
  - By Family Size
  - By Property Type
